---
title: Requests
description: Hold requests for your approval and limit how much each user can request.
---

Pulsarr sends most watchlist items straight to Sonarr or Radarr. An item waits in the approval queue instead when the user requires approval, when it puts them over their quota, or when a Content router route asks for approval.
